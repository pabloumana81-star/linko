## Severidad

- **S0:** incidente de seguridad/privacidad o bloqueo crítico de toda la beta.
- **S1:** un flujo crítico no puede continuar.
- **S2:** defecto importante con una alternativa temporal.
- **S3:** defecto cosmético o menor.

Un reporte S0 debe enviarse por el canal de incidentes `[POR DEFINIR]`. No
incluyas el secreto o documento expuesto: describe el tipo de dato, pantalla y
momento, y espera instrucciones seguras.
