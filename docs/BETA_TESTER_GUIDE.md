# Guía para testers de la beta de LinkO

LinkO conecta clientes con profesionales. Esta beta es una versión de prueba:
puede contener errores, cambiar y no estar disponible de forma continua. Usa
solo datos adecuados para una prueba y sigue las instrucciones de acceso que
recibirás por el canal oficial.

Acceso a la beta: `[ENLACE O INVITACIÓN POR DEFINIR]`  
Canal de soporte: `[POR DEFINIR]`  
Periodo de prueba: `[POR DEFINIR]`

## Si pruebas como cliente

1. Inicia sesión y completa el onboarding customer.
2. Explora categorías, abre discovery y revisa un perfil profesional.
3. Crea una solicitud, elige profesional y envíala.
4. Revisa cambios de estado y conversa por chat.
5. Completa el flujo del servicio y envía una valoración cuando corresponda.
6. Cierra sesión, vuelve a entrar y comprueba que tu estado se restaure.

## Si pruebas como profesional

1. Inicia sesión y completa el onboarding professional.
2. Crea o edita tu perfil y prueba agregar/eliminar una imagen de portafolio.
3. Sigue las instrucciones operativas antes de cargar cualquier documento de
   verificación; usa exclusivamente material autorizado para la beta.
4. Recibe una solicitud, acéptala o recházala si la opción está disponible.
5. Usa chat, cotización, programación y finalización del servicio.
6. Cierra sesión, vuelve a entrar y comprueba que tu estado se restaure.

## Qué reportar

Reporta bloqueos, cierres inesperados, pantallas vacías, datos incorrectos,
acciones que no se sincronizan, mensajes duplicados, problemas de login,
archivos que no cargan, contenido privado visible para otra cuenta, texto
cortado y dificultades de accesibilidad.

Usa `BETA_BUG_REPORT_TEMPLATE.md` e incluye dispositivo, sistema operativo,
versión/build de LinkO, rol, pantalla, pasos, resultado esperado/real,
frecuencia y estado de red. Adjunta captura o video solo si no revela datos
privados.

**Nunca incluyas contraseñas, códigos de acceso o Magic Link, tokens,
credenciales, documentos de identidad/verificación, URLs privadas ni otros
secretos en un reporte, captura o video.** Si sospechas un incidente de
seguridad o privacidad, clasifícalo S0 y contacta el canal oficial
`[POR DEFINIR]` sin copiar el dato sensible.
