# Linko Development Rules

You are building Linko, a trust-based marketplace connecting customers with professionals.

General rules:
- Never generate placeholder code.
- Keep architecture modular and scalable.
- Use Clean Architecture.
- Use Riverpod for state management.
- Use GoRouter for navigation.
- Use Supabase as backend.
- Use Material 3.
- Keep widgets small and reusable.
- Always explain major architectural decisions before making them.
- Never modify existing files unless requested.
